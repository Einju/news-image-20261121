A Python program that draws a 1024x1024 newspaper front page summing up Saturday 21 November 2026's world news: two M6.8 earthquakes on the same day (Peru and the Banda Sea), the COP31 climate talks running into Saturday without a deal, and a fire at the Hartha power station in Basra that killed four people. Pure standard library, deterministic: it renders at 2048x2048 and downsamples to 1024x1024, and every run writes the same PNG bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
